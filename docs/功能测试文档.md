# **🧪 核心功能测试用例与预期结果 (Test Cases)**

本文档旨在为二次开发者及 QA 提供系统核心功能的测试指引。请确保在拥有 .env 环境变量的测试环境（或 Docker 中）进行以下测试。

## **1\. 认证与会话模块 (Auth & Session)**

| 测试编号 | 测试模块 | 测试动作 (Action) | 预期结果 (Expected Result) | 状态 |
| :---- | :---- | :---- | :---- | :---- |
| **AUTH-01** | 用户注册 | 向 /api/v1/auth/register 发送有效邮箱和符合正则强度的密码 | 返回 201 Created，返回包含 Token 和 user\_id 的 JSON | ✅ |
| **AUTH-02** | 弱密码拦截 | 向注册接口发送密码 "123456" | 返回 422/400 错误，提示必须包含大小写字母和特殊字符 | ✅ |
| **AUTH-03** | 用户登录 | 向 /api/v1/auth/login 发送正确的账号密码 (OAuth2表单格式) | 返回 access\_token 及 bearer 类型 | ✅ |
| **AUTH-04** | 会话创建 | 携带 Token 调用 POST /api/v1/sessions | 数据库 session 和 thread 表新增记录，返回 session\_id | ✅ |

## **2\. 核心对话与流式输出 (Chatbot Core)**

| 测试编号 | 测试模块 | 测试动作 (Action) | 预期结果 (Expected Result) | 状态 |
| :---- | :---- | :---- | :---- | :---- |
| **CHAT-01** | 普通对话 | 选择已发布 Agent，携带 Token 向 /api/v1/agents/{agentId}/chat/stream 发送 "你好" (关闭所有功能开关) | 收到流式回复，不触发任何工具调用 | ✅ |
| **CHAT-02** | 流式输出 | 向 /api/v1/agents/{agentId}/chat/stream 发送请求，要求写一首长诗 | HTTP 响应为分块传输流 (Chunked)，前端可按打字机效果逐字渲染 | ✅ |
| **CHAT-03** | 历史记忆 | 对着同一个 session\_id 提问 "我刚才第一句话问了你什么？" | 能够准确回答上下文（因 LangGraph 自动读取了 DB 中的 Checkpoint） | ✅ |
| **CHAT-04** | 滚动摘要 | 单个会话连续发送超过 10 条（触发 SUMMARY\_THRESHOLD）长消息 | 数据库日志显示触发了摘要压缩机制，旧消息转入 summary 状态字段以节省 Token | ✅ |

## **3\. 动态工具箱 (Agent Tools) \- 需配置好 API Key**

| 测试编号 | 测试模块 | 测试动作 (Action) | 预期结果 (Expected Result) | 状态 |
| :---- | :---- | :---- | :---- | :---- |
| **TOOL-01** | 联网搜索 | 开启 web\_search: true，询问 "今天的北京天气如何？" | 后台日志显示调用了 Tavily 或 DuckDuckGo 工具，AI 回答包含最新实时数据 | ✅ |
| **TOOL-02** | 代码沙盒 | 开启 code\_interpreter: true，提问 "计算 998244353 的平方根并保留 10 位小数" | 后台调用 Python REPL 节点，执行运算后返回极其精准的数学结果 | ✅ |
| **TOOL-03** | 长期记忆 | 开启 memory\_tools: true，告知 "我叫张三，对海鲜过敏" | 后端调用 save\_memory 将内容存入 memory 表，提示已记住 | ✅ |
| **TOOL-04** | 记忆检索 | 新建一个会话（新 session\_id），询问 "你还记得我叫什么，不能吃什么吗？" | AI 自动触发 search\_memory 工具，从长期库中准确检索到过敏信息 | ✅ |
